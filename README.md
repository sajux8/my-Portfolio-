Mekarasa Sajikanth | Portfolio Website  LIVE:https://sajikanth-portfolio.vercel.app/
 
A simple, responsive personal portfolio website built with plain HTML, CSS and JavaScript. No frameworks or build tools needed.

Features
Sections: Home, About, Skills, Experience & Education, Projects, Contact
Dark / light theme toggle (remembers your choice and follows your system setting by default)
Mobile-friendly layout with a collapsible menu
Smooth scrolling and hover effects
Footer year updates automatically
Project structure
sajikanth-portfolio/
├── index.html   # page content
├── style.css    # styling and themes
├── script.js    # menu, theme toggle, footer year
└── README.md    # this file
How to run
Unzip the folder.
Open index.html in any web browser.

That's it. No installation required.

How to customize

Open the files in a text editor (such as VS Code) and search for TODO:

What to update	Where
Email address	Contact section in index.html
GitHub and LinkedIn links	Contact section in index.html
CV download link	Contact section in index.html (add your PDF to the folder and link to it, e.g. href="cv.pdf")
Project GitHub links	Projects section in index.html
Internship details	Experience section in index.html
Skills	Skills section in index.html
Colors	CSS variables at the top of style.css (--accent, --bg, etc.)
Deploying for free

GitHub Pages

Create a new repository on GitHub and upload the files.
Go to Settings > Pages.
Under "Build and deployment", choose the main branch and the root folder, then save.
Your site will be live at https://<your-username>.github.io/<repository-name>/.

Netlify

Go to netlify.com and sign in.
Drag and drop the project folder onto the deploy area.
Your site gets a live link right away.
